open-source AI model
  • Own AI service: a free, open-source model runs on this server. There is no paid AI API behind it.
  • Streaming: words are sent the moment they are generated (Server-Sent Events), so you start reading right away.
  • Many users: the server answers a few people at a time; others wait in a short line; if the line is full it replies "busy" instead of crashing.
  • Measured: every answer records time-to-first-word and words (tokens) per second.
  • OpenAI-compatible: code written for OpenAI's API works here by changing one URL.

For engineers: Python 3.12 · FastAPI · asyncio semaphore + bounded queue · SSE · pytest + GitHub Actions. Try the endpoints in the interactive API docs or read the source code.
